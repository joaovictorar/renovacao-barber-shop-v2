# Renovação Barber Shop - Agendamento Completo

Versão sem Calendly, feita em HTML, CSS e JavaScript puro.

## Recursos

- Escolha de serviço
- Escolha de profissional
- Fotos/avatares dos profissionais
- Escolha de data
- Escolha de horário
- Bloqueio de horário já reservado para o mesmo profissional
- Minhas Reservas
- Cancelar reserva
- Enviar reserva pelo WhatsApp
- Google Maps integrado

## Importante

Esta versão salva as reservas no navegador usando localStorage. É ótima para demonstração e apresentação ao cliente.

Para produção real com vários clientes usando ao mesmo tempo, o próximo passo é criar backend com Node.js + banco MongoDB.
